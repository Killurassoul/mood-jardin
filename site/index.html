Installer sur Android

Quatre gestes

  1. Télécharge le fichier APK sur ton téléphone.
  2. Ouvre-le depuis « Fichiers » ou la notification.
  3. Si Android demande, autorise les applications inconnues pour cette installation.
  4. Appuie sur « Installer », puis ouvre Mood Jardin.

Installer sur Windows

Trois clics

  1. Lance « Mood Jardin Setup 1.0.0.exe ».
  2. Si Windows affiche un avertissement bleu : « Informations complémentaires », puis « Exécuter quand même ».
  3. Clique sur « Suivant » puis « Installer ». L’icône apparaît sur ton bureau.
